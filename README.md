# 🛠️ Auto-Data-Preprocessor: Умный пайплайн очистки данных

## Описание проекта
Этот pet-проект представляет собой автоматизированный пайплайн для предобработки "грязных" данных перед обучением ML-моделей. Проект создавался для автоматизации рутинных задач аналитика и дата-сайентиста. 

Главная особенность проекта — архитектурное разделение бизнес-логики и интерфейса. Проект состоит из математического ядра (`core.py`), интерактивного консольного приложения (`main.py`) и демонстрационного Jupyter Notebook (`demo_showcase.ipynb`), где пайплайн применяется к классическому датасету House Prices.

## Ключевые возможности (Core Features)
* **Smart Types (Приведение типов):** Автоматический поиск скрытых категорий (числа с малым количеством уникальных значений) и их перевод в текст. Распознавание строковых дат и парсинг на год, месяц, день, час и т.д..
* **Умная обработка пропусков (Smart Imputation):** Гибкая логика заливки пропусков медианой/модой или выделение их в отдельный категориальный класс `None`. Удаление мусорных столбцов с высоким процентом NaN на основе их корреляции с целевой переменной.
* **Поиск выбросов (Outliers Detection):** Поддержка как классического одномерного квантильного отсечения, так и многомерного поиска аномалий с помощью алгоритма `IsolationForest`.
* **Отбор признаков (Feature Selection):** Фильтрация бесполезных признаков с помощью оценки взаимной информации (Mutual Information) для текста и коэффициента корреляции для чисел. Удаление дублирующих признаков для борьбы с мультиколлинеарностью.
* **Подготовка к ML:** Стандартизация числовых признаков (`StandardScaler`), бинарное кодирование текста (`One-Hot Encoding`) и опциональное сжатие пространства признаков с сохранением заданной дисперсии с помощью PCA.

## Структура проекта
1. `core.py` — "Движок". Библиотека независимых математических функций для трансформации данных.
2. `main.py` — Интерактивный CLI-интерфейс, который в формате диалога проводит пользователя по всем этапам очистки датасета.
3. `demo_showcase.ipynb` — Демонстрация работы модулей ядра без ручного ввода на примере реального датасета (House Prices https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data).
